# lootprompt.com — page brief

Source: `https://lootprompt.com/` (TanStack Start + React 19 + Tailwind v4, data from a public
Supabase project). Captured 2026-10-17 at 1440×900 and 390×844.

## Page-wide

- Background `.paper-grid` (graph paper, drifts by `scrollY * 0.06` via `--paper-shift`), animated
  film grain on `body::before`. Light theme default, `.dark` on `<html>` from `localStorage["pda:theme"]`
  or `prefers-color-scheme`.
- Fonts (Google): Inter Tight 400/500/600 (`--font-ui`, body), Caveat 500/600/700 (`--font-hand`),
  Alex Brush (`--font-script`, hero signature), Cormorant Garamond 400/500 (`--font-serif`, synthesized
  italic). Mono stack `"IBM Plex Mono", SFMono-Regular, Consolas, monospace` — Plex is *not* loaded by the
  source, so it falls back to the system mono; keep it that way.
- Content column: `max-w-6xl` (1152px) with `px-5 sm:px-6`; hero `max-w-5xl`.
- Scroll-driven CSS: `.scroll-rise` (view timeline), `.scroll-parallax-hero/-sub` (root scroll).
- Fixed chrome: header actions top-right (3D vault lock button, theme toggle, "Join the crew"), invideo
  hanging tag top-left (mobile: banner under header), "Your thief file is waiting" crew window
  bottom-left (mobile: compact pill), vault presence pill (behind crew window), bell bottom-right.

## Styles

`src/components/sites/lootprompt/lootprompt.css` holds the source's component rules, filtered to classes
referenced by the homepage. Tailwind utilities in JSX are generated by this project with the same
theme tokens (`src/app/globals.css`), so source class strings can be reused verbatim.

## Build status (2026-10-19)

Every section above is rebuilt as React components under `src/components/sites/lootprompt/`
(one folder per section) and checked side by side against the source at 390, 768, 1440 and
1920 px, light and dark. At 1440 the local page height (13,850 px) and the grid's offset
(3,955 px) match the source exactly. Comparisons: `docs/design-references/lootprompt/comparison-*.jpg`
(source on the left of each pair).

Interactions reproduced for a signed-out guest: theme toggle, invideo tag swing / dismiss,
crew window, members-only and crew-only gates, sign-up dialog (Sign up / Log in), vault
presence pill and floor panel, bell panel, hero signature intro and letter-stealing hook,
Top Thieves period toggle and 50-row crew list, job board, heist report case file, vault
crack and archive, vault 3D preview tilt, Most Stolen hide/show, category tabs, search (`/`),
sort, orientation / not-stolen / brand pills, Surprise me (`R`), save heart, `?` shortcuts,
⌘K palette, Instagram reel carousel, ink-pad fingerprint.

### Known differences

- Data is the 2026-10-17 snapshot; the live site has since added prompts and moved its counters.
- Hover / featured motion plays MP4 re-encodes of the source GIFs (headless Playwright Chromium
  cannot decode H.264, so automated screenshots show posters; browsers play them).
- Video references (`.mov`/`.mp4`) still point at the source's storage.
- Sign-up / log-in submits, Google sign-in and all out-of-scope routes go to lootprompt.com.
- Realtime features are static: the vault pill shows the captured 4 thieves; no live steal
  glow, thief overlay, wave notifications or bell notifications.
- Not rebuilt (rare or signed-in only): monthly heist report popup, CCTV easter egg, rank-up /
  badge / coin-purse / goodbye moments, WANTED poster, signed-in header and missions panel.
- The ink-pad guestbook stores prints in this browser only (no database writes).
- Deliberate fix: grid reveals and steal counters also fire for cards a fast scroll skips past
  (the source can leave those counters at 0).

### Refreshing the snapshot

`LOOTPROMPT_ANON_KEY=<publishable key from the site bundle> python3 scripts/lootprompt/fetch-assets.py`
re-downloads posters / thumbnails / logos, re-encodes new GIFs and rewrites `data/*.json`.
